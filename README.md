
# Network Configuration Project

Cisco Packet Tracer

## 1. Project Overview

Designed and configured a small 
computer network using Cisco Packet Tracer
to connect multiple devices and test network connectivity.

## 2. Network Components

- PCs
- Network Switches
- Wireless Access Point
- Network Printer
- Ethernet Connections

## 3. Project Objectives

- Connect multiple computers within a network.
- Configure IP addressing.
- Connect wireless devices through an Access Point.
- Connect a network printer.
- Test communication between network devices.

## 4. Implementation

- Designed the network topology.
- Configured IP addresses for network devices.
- Connected computers through network switches.
- Configured wireless connectivity.
- Connected and tested the network printer.

## 5. Connectivity Testing

Used the Ping command to test 
connectivity between computers and the network printer.

Identified and troubleshot a connectivity 
issue affecting some computers, then 
successfully restored communication.
